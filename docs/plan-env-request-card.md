# 工具缺環境變數時,AI 在聊天裡出「登入 / 設定」卡片

**狀態:** grill 完成(2026-10-08),待施工。
**來源標記:** 〔user〕= user 的原話或明確選擇;〔查證〕= 讀 `origin/master` 程式碼確認的事實;〔施工〕= 我定的實作細節,可推翻。

## 1. 問題〔查證〕

套件工具缺憑證時照慣例 exit 3(`agent/exit_codes.py` `BLOCKED`;作者端 `tool-starter` 的 `NeedsAction`),
並在 stderr 用一句話寫出缺哪個變數。模型拿到的提示是「告訴使用者去環境變數面板設定」——於是 AI 只能用文字說
「請到右上角 Env 設定 `MAP_KEY`」,使用者得自己找按鈕、找那一格、知道要不要登入。

已經有的零件:

- 前端能把一個缺的變數分成「登入」或「手動設定」:有登入方式(`IEnvProvider`,`produces` 含這個名字)就是登入,
  否則是設定(`web/src/lib/identityState.ts`)。頁面工具列的「Sign in to ERP / Set MAP_KEY」就是這樣來的。
- 環境變數面板 `EnvVarsModal`:「我的」(private)/「共用」(shared)兩頁,登入按鈕在面板裡;目前只能從聊天標頭的
  Env 按鈕打開,不能指定開哪一頁、聚焦哪一格或直接進某個登入。
- AI 叫出 UI 的既有做法:內建工具 + 前端依工具名/結果尾端標記畫卡片(`show_file`、`show_skill_hub_entry`、`ask_user`)。
- 缺哪個變數**只**寫在 stderr 的文字裡;`env.json`(工具宣告需要哪些變數)repo 裡沒有任何工具寫。
- **`exec` 跑的指令拿不到 item 的環境變數**——只有套件工具會拿到(`registry._tool_env`;`exec_impl` 不傳 `env`)。

## 2. 決定

| # | 決定 | 來源 |
|---|---|---|
| N1 | **由 AI 決定要不要出卡片**:新內建工具,AI 從工具輸出讀出缺的變數名後呼叫它;平台判斷每個名字是「登入」還是「設定」,在聊天裡畫卡片。 | 〔user〕「A」 |
| N2 | **`exec` 的錯誤不出卡片**:`exec` 跑的指令拿不到環境變數,設了也沒用。 | 〔user〕「但要注意 exec 的錯誤都不會吃環境變數」 |
| N3 | **turn 停在卡片**(和 `ask_user` 一樣)。卡片上每個缺的變數一顆按鈕:「登入 X」直接打開那個登入方式的對話框;「設定 Y」打開面板並標出那一格。存檔後那一列變「已設定 ✓」,卡片出現「重試」按鈕,按下送出一則訊息,AI 重跑那支工具。不自動重試。 | 〔user〕「A」 |
| N4 | **從卡片打開的面板預設在「我的」頁**;要放共用,使用者在面板裡自己切到「共用」頁。卡片上不加切換。 | 〔user〕「A 但用戶可選」→「A」 |

## 3. 施工時我定的事〔施工〕

| # | 定了什麼 | 為什麼 |
|---|---|---|
| D1 | 工具形狀:`request_env(tool, names, reason)`。`tool` = 失敗的那支**套件工具**的名字(模型看到的名字);`names` = 缺的變數名;`reason` = 一句給人看的話。 | N2 要擋得住,就得知道是哪支工具。 |
| D2 | 平台拒絕(回一句話給模型,不出卡片):`tool` 是 `exec` 或其他內建工具 →「這個指令拿不到環境變數,設了也沒用」;`tool` 不是這個 turn 拿到的套件工具 → 拒絕;名字不合 `.env` 格式 → 拒絕。 | N2;不能為不存在的工具要變數。 |
| D3 | 變數名的來源要可查:名字必須出現在**這個 turn 裡那支工具最後一次的輸出**,或那支工具的 `env.json` 裡;都沒有就拒絕,告訴模型「`X` 沒有出現在 `tool` 的輸出裡」。 | 擋住模型自己編名字,讓使用者白設一個沒人讀的變數。 |
| D4 | 卡片的狀態每次畫都重算(看這個人目前看得到的值),不存在卡片裡:重新整理、隔天打開都正確;另一個人打開同一段對話,看到的是**他自己的**狀態,按鈕作用在他自己的「我的」頁。 | 卡片說的必須是現在的事實。 |
| D5 | 「設定 Y」但面板裡沒有 Y 這一列(工具沒寫 `env.json`)時,面板先加上這一列(名字填好、值空白)再聚焦。 | 否則按鈕打開面板卻找不到要填哪裡。 |
| D6 | 誰拿得到這個工具:和 `ask_user` 同一批——sub-agent 不給(`apps/subagents.py`),沒有人能按按鈕的執行也不給。 | 沒人按的卡片只會讓 turn 停住。 |
| D7 | exit 3 的提示(`exit_codes.py` `BLOCKED` 與 `mcp_server.py` 的副本)改成叫模型呼叫 `request_env`,不再叫它用文字指路。 | 讓 AI 知道有這張卡片可用。 |

## 4. Phases

| Phase | 內容 |
|---|---|
| P1 | 後端:`request_env` 內建工具(D1–D3、D6),turn 停在它(N3),結果尾端帶標記;exit 3 提示(D7) |
| P2 | 前端:卡片(登入 / 設定分類沿用 `identityState`;狀態即時重算 D4;「重試」按鈕) |
| P3 | 前端:面板能從外面打開並指定「我的」頁、聚焦某一格(含 D5)、直接進某個登入對話框 |
| P4 | 文件:`docs/tool-authoring.md` exit 3 一節、`extending-the-platform.md`;`docs/migrations.md` 一條(行為改變) |
| P5 | review 回合、CI、PR、`/web-demo` |

## 5. 不做

- 不自動重試(N3)。
- 不改 `exec` 拿不到環境變數這件事。
- 不在 WUI 頁面上出這張卡片(頁面已經有 `workspace.openLogin()` 和工具列的鑰匙按鈕)。
