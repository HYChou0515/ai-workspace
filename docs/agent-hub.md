# Agent Hub：發布給別人對話的 agent

一個 **agent** 是 workspace 裡任何資料夾的一份 `agent.ai.yaml`。發布之後它列在 **Agent Hub**
（導覽列 WUI 旁邊的入口，`/agents`）；每個人跟它開一個新對話，就拿到**一份自己的 workspace
副本**，在裡面跟這個 agent 對話。

它跟 WUI 是兩種東西：WUI 是一個**頁面**，agent 是一個**對話對象**。底下共用同一套「發布＝存一份
快照，打開＝複製一份」的機制（`docs/plan-wui-publish-and-agent-hub.md`），但入口、名字、問的問題
都不一樣。它也跟子代理（`.agent/<名字>/AGENT.md`，對話中途 `run_agent` 叫的那種）無關。

## 寫一個 agent

```yaml
view: agent
title: 業務小幫手              # 在 Agent Hub 的名字，必填
description: 回答這一季訂單的問題。
icon: chart                     # 資料夾裡的圖檔、emoji，或平台圖示名
color: "#3B82F6"
instructions: |                 # 必填：這個 agent 跟 App 本身不一樣的地方
  你協助業務團隊查 data/ 底下的訂單。
  每個答案都標出你讀的是哪一張訂單。
tools: [read_file, list_files]  # 選填，只能縮小
suggestions:                    # 新對話一開始的建議
  - 這週有哪些訂單延遲出貨？
publish:                        # 發布對話框打開時帶的答案
  reach: everyone
```

- **`instructions:` 就是這個 agent**：每一輪對話都加在 App 原本的指示後面。
- **`tools:` 只能縮小**：跟這個 App 給這個 workspace 的工具取交集，列了 App 沒有的名字也不會多出來
  （agent 面板會寫出來）。不寫就是 App 的全部工具。沒有欄位能換模型、換 preset 或加新工具。
- **技能和 workflow** 是 workspace 根目錄的，加上它自己資料夾的 `.skill/`、`.workflows/`；同名的話
  資料夾裡的那份贏。對話副本做出來時，資料夾的那份已經放到副本的根目錄。
- 檔案裡有看不懂的欄位（例如打錯成 `instruction:`），agent 面板會點名，而且**不能發布**——
  不然副本會在少了那一段的情況下默默跑。

## agent 面板：發布前先看別人會拿到什麼

在 workspace 裡打開 `agent.ai.yaml`，看到的是 **agent 面板**（要看原始 yaml，按編輯）：

- 名字、說明、圖示；一段對話**實際會有的工具和技能**——是伺服器照真正跑一輪對話的那條路算出來的，
  不是另外推的；`tools:` 裡 App 沒有的名字另外列出。
- 檔案有問題時列出問題。
- 發布狀態：還沒發布，或誰在什麼時候發布的、誰能用、「N 次打開 · M 人」、最近幾則更新說明。
- **測試對話**：在旁邊開一個新對話，用這個 agent 的指示、工具和技能回答，跑在**你自己的**
  workspace（不是副本）。測試對話不會變成這個 item 的預設對話。
- **發布 agent**、已發布時的**再次發布 agent**和**停止發布**（會先問一次）。

## 發布 agent

只有能管理這個 workspace 分享設定的人能發布。對話框問：

1. **誰能用**——只有我／指定的人或群組／所有登入的人。
2. **每個對話副本的沙盒大小**——空著用平台預設。
3. **再次發布時，這次改了什麼**（選填）——寫進更新說明，agent 的頁面列最近五則。

agent 不問「副本怎麼分」：**一律每個對話一份**。對話框也會算好一份副本有多少檔案、多大、大概
要等多久。

!!! warning "個人 token 不要放在 Shared"

    副本帶著原本 workspace **Shared** 環境變數當下的值。放在 Shared 的 token 等於發給每一個開對話的人；
    個人的 token 請各自放在「我的環境」。

再次發布只改**之後的**新對話從哪一版開始；已經在進行的對話留著自己那份。停止發布會從 Agent Hub
拿掉、刪掉快照；已經開的對話和那份 `agent.ai.yaml` 都還在。原本的 workspace 刪掉時，它發布的 agent
一起下架。

## Agent Hub

`/agents` 的版面跟 WUI 總覽一樣：卡片（有圖示，沒有圖示時是標題第一個字的圓圈）、可以切成清單、
右上角一顆星加入我的最愛（Agent Hub 的星和 WUI 總覽的分開記）、搜尋、排序。列的是**發布給你的**
agent；使用量只有數字，不列是誰。

點進一個 agent 是它的頁面：說明、誰發布的、什麼時候、使用量；最上面一顆**開始新對話**；最近的
更新說明；下面是**我和它的對話**——每一個都是你的一份副本，寫著你問的第一句話、什麼時候開的、
佔多少空間，可以勾選幾個一起刪掉（會先問一次，空間還給你）。

## 跟 agent 的對話

開始新對話會先到「正在準備你的副本…」，做好就進到那個對話：最上面是「← 回到 Agent Hub」和
agent 的名字，中間是對話，**沒有「新對話」**——要新的一段就回 Agent Hub 再開一個。workspace 的檔案、
環境、工具還在旁邊，收起來而已；`show_file` 照常會把檔案叫出來。在你的 App 首頁它是一個普通的
item，多一行「來自 agent「名字」」。
